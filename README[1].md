# 蔡佑林 — Portfolio

一個無框架、可直接部署到 GitHub Pages 的個人作品集網站。

## 先改這 5 個地方

1. `index.html`：把 `蔡佑林` 改成你的名字。
2. 把 `your.email@example.com` 改成你的 Email。
3. 把 `yourusername` 改成你的 GitHub 帳號。
4. 把「Campus Explorer / Study Flow / Generative Garden」換成你的真實作品與連結。
5. 如果教授要求放照片，可以之後加入自己的照片或作品截圖。

## 本機預覽

直接雙擊 `index.html` 即可預覽。

## 上傳 GitHub

```bash
git init
git add .
git commit -m "Create personal portfolio"
git branch -M main
git remote add origin https://github.com/your-github-username/YOUR_REPOSITORY.git
git push -u origin main
```

然後到 GitHub：
**Repository → Settings → Pages → Deploy from a branch → main / root → Save**

幾分鐘後就會得到 GitHub Pages 網址。
